# AI Agent 是來解決你的問題的

一個單頁中文說明頁：**AI Agent 唔係教你用工具，係幫你解決問題。**
你只需要講清楚問題，其他交給 Agent。

A single-file Chinese landing page explaining what an AI agent really is:
a problem solver, not another tool you have to learn.

## 內容 Contents

- 傳統軟件 vs AI Agent 的對照
- 真實例子：以前 30 分鐘一個案件，現在 10 分鐘做 20 個
- 可切換示範：案件分流 / 相片整理 / 寫電郵追文件
- Agent 的五步循環：聽懂問題 → 拆解步驟 → 動手做 → 自我檢查 → 交回成果
- 你可以叫佢做嘅事

## 使用 Usage

- 檔案 File: `index.html`
- 單一檔案、零依賴、可離線使用 — 直接用瀏覽器打開即可
- Single file, no dependencies, works offline — just open it in a browser

## 技術 Technical

- 純 HTML + CSS + 少量原生 JavaScript（示範切換、滾動淡入）
- 深色主題、漸變光暈背景、手機自適應
- 尊重 `prefers-reduced-motion`
